# Sales Performance Analysis

*Developed by Ritu Raj Singh*

## Project Overview

This project focuses on analyzing sales data to identify key business insights related to sales, profit, orders, products, categories, and cities.

## Project Workflow

- Data cleaning and preparation using Microsoft Excel
- Analysis of the cleaned CSV dataset
- KPI calculation and business analysis
- Tableau visualization and dashboard creation
- Identification of sales and profit trends

## Dataset

The project uses the cleaned dataset:

Cleaned_Sample_Dataset.csv

The same cleaned CSV file is used for analysis and Tableau visualization to maintain consistency throughout the project.

## Key Analysis

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Monthly Sales and Profit Trends
- Category-wise Sales Performance
- Top 5 Products by Sales
- City-wise Sales Performance
- Order Status Analysis

## Tableau Dashboard

The Tableau dashboard provides an interactive view of sales performance using KPIs, trend analysis, category performance, top products, and city-wise performance.

## Tools Used

- Microsoft Excel
- Python
- Pandas
- Tableau
- GitHub

## Outcome

The project provides a clear view of overall sales performance and helps identify important trends, profitable areas, top-performing products, and business performance across categories and cities.
